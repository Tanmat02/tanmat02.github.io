# 한정민 활동 기록

전주대학교 기계자동차공학과 4학년(복수전공 축구학과). 자작 전기자동차를 만들고 있고, 이 차에 자율주행을 넣는 것이 다음 목표입니다.

이 저장소는 프로젝트, 교육, 수업, 자격증을 한곳에 모은 개인 활동 DB입니다. `index.html`을 열면 분류별로 걸러 보고 검색할 수 있습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | DB 화면 (분류 필터, 분류별 카드, 검색, 항목 펼쳐 보기) |
| `data/items.js` | 모든 항목 데이터. 새 활동은 여기에 추가 |
| `projects/` | 프로젝트별 상세 페이지 (준비 중) |
| `assets/` | 그림·사진 (본인 확인 후 추가) |

## 항목 추가 방법

`data/items.js`의 `ITEMS` 배열에 아래 형식으로 하나를 더 넣습니다.

```js
{
  id: "고유-이름",
  category: "프로젝트",          // 프로젝트 | 교육 | 수업 | 수상 | 자격증 | 목표
  title: "이름",
  org: "기관·팀·역할",
  start: "2026.03", end: "2026.06",
  status: "완료",                // 완료 | 진행 중 | 예정 | 계획
  tags: ["키워드"],
  summary: "한두 문장 설명",
  did: [], learned: [], results: [], links: []
}
```

## 공개 원칙

- 성적은 과목별 등급과 학기·전체 평점까지 적는다. 백분율 점수와 증명서 원본은 올리지 않는다.
- 학번, 전화번호, 이메일, 다른 사람 이름은 올리지 않는다.
- 피지컬 AI 과정 프로젝트는 주제가 과정에서 정해졌고 코드는 AI 도구로 구성했다는 점을 함께 적는다.
